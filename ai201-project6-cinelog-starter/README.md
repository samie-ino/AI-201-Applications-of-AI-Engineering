# AI-201 Applications of AI Engineering

This repository contains the coursework, laboratory assignments, and projects completed for **AI-201: Applications of AI Engineering**. Throughout this course, I explored the design and implementation of practical AI systems using Python, focusing on problem solving, intelligent decision-making, and real-world AI applications.

## Repository Structure

The repository is organized by labs and projects completed during the semester.

### Labs

* **Lab 1 – RulesBot**
  Developed a rule-based chatbot that makes decisions using predefined logical rules.

* **Lab 2 – Plant Advisor**
  Created an AI assistant that recommends plant care based on user input and environmental conditions.

* **Lab 3 – Pod Classifier**
  Built a classification system that categorizes input data using AI techniques.

* **Lab 4 – RepairSafe**
  Developed an intelligent assistant that provides repair guidance while emphasizing safety and proper procedures.

### Projects

* **Project 1 – Unofficial Guide**
  Designed an AI-powered guide that assists users by organizing and presenting information in a structured format.

* **Project 2 – FitFindr**
  Developed an AI application that recommends fitness-related options based on user preferences.

* **Project 3 – TakeMeter**
  Created an AI system for evaluating and analyzing user-generated content.

* **Project 4 – Provenance Guard**
  Built an AI solution focused on verifying information provenance and improving trustworthiness.

* **Project 5 – Mixtape**
  Developed an AI-powered recommendation system for generating personalized playlists.
